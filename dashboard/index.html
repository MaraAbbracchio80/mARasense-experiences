MaraSense Experience Manager

Dashboard privata per creare e aggiornare esperienze AR automatiche. La cartella apps resta intoccabile.

Apri esperienza esistente

Quando apri un'esperienza, il Manager mostra i file gia caricati. Per sostituirli, carica nuovi file nei campi sotto e premi di nuovo Crea esperienza.

Nuova esperienza / Modifica

Puoi lasciare vuoto: il Manager genera automaticamente targets.mind dalle immagini target. Carica un .mind solo se vuoi sostituire/forzare quello compilato.

Ordine reale del target index: immagine 1 = target 0, immagine 2 = target 1, ecc.

Ogni contenuto puo essere assegnato a uno o piu target.
